# SID ChatBot

A free ChatGPT-style chatbot interface built with plain HTML, CSS, and JavaScript.

## Features
- Clean, responsive chat UI
- Instant local bot replies (no paid API required)
- Predefined smart replies for common prompts
- Dynamic fallback responses for any message

## Run locally
```bash
python3 -m http.server 4173
```
Then open `http://localhost:4173`.

## Project files
- `index.html` — app layout
- `style.css` — visual styles
- `script.js` — chatbot interaction logic
